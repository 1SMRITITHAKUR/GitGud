# Pull Request Guidelines

A pull request (PR) is how you ask the repository maintainers to review and include your changes. Open one after your team has finished its meme submission.

## Title Enforced Format
When creating your PR, please ensure your title follows this format (GitHub does not auto-fill PR titles from templates, so you'll need to type this in yourself):
```text
Add meme: <team name>
```
*Example:* `Add meme: git-ninjas`

## Submission Process
1. Complete your work in your team's branch.
2. Open a new Pull Request against the default branch.
3. The description field will auto-fill with the submission template.
4. Fill out the requested fields (Team name, directory, meme name, and description).
5. Go through the checklist item by item using the guide below.
6. Once all items are verified, check the boxes, review your changes, and click **Create pull request**.

## How to Fill Out the Checklist

In the pull request description, replace each unchecked box, `[ ]`, with a
checked box, `[x]`, only after you have verified that item. You can click the
checkboxes in GitHub's editor, or type the brackets yourself.

Use these checks as a guide:

- **The submission directory is named after the team:** Confirm the folder
	under `submissions/` uses your team's name and matches the Team field.
- **`meme_name.txt` contains the exact meme name:** Compare the file's single
	line with the name provided by the website. Remove any extra text.
- **The caption files match the template:** Confirm you have exactly the
	required caption files, in the correct order, such as `caption1.txt` and
	`caption2.txt`.
- **Team members contributed through branches and pull requests:** Confirm
	each team member made their change through a branch and pull request.
- **Captions are short and valid:** Read every caption and confirm it is
	readable and does not contain `/`, `?`, or `#`.
- **The meme follows the submission guidelines:** Check the content against
	every rule in the [submission guidelines](../README.md#submission-guidelines).
- **No generated images or unrelated files are included:** Review the
	**Files changed** tab and confirm the PR contains only the intended
	submission files.

Do not check an item just because it looks familiar. If an item is not true,
fix the submission first and leave its box unchecked until it is verified.
